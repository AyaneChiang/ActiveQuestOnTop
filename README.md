# Active Quest On Top（作用中任務置頂）

《魔獸世界：永恆》（World of Warcraft: Forever）插件。讓你最後操作的任務，永遠排在畫面任務追蹤列表的最上方。

## 功能

以下任一操作，都會把該任務移到追蹤列表第一位：

| 操作 | 結果 |
|---|---|
| 點任務標題 | 該任務排第一 |
| 點任務前的圖示（設為專注） | 該任務排第一，專注保留 |
| 加入追蹤（手動追蹤，或接任務時自動追蹤） | 該任務排第一 |

- 遊戲依距離重新排序追蹤列表後，置頂的任務會自動回到第一位。
- 置頂的任務被取消追蹤或完成後，插件不再干預排序，直到你下一次操作。
- 插件只調整排序，不會替你更改專注的任務。所以排第一的任務不一定是專注任務，例如專注在 A 時再追蹤 C，結果是 C 第一、A 第二，專注仍在 A。

## 安裝

1. 下載本專案，資料夾名稱必須是 `ActiveQuestOnTop`。
2. 把資料夾放進永恆版本用戶端的 `Interface\AddOns\` 目錄。
3. 重新啟動遊戲，或在遊戲內輸入 `/reload`，並在插件清單確認已啟用。

## 指令

| 指令 | 說明 |
|---|---|
| `/aqot` 或 `/aqot toggle` | 切換啟用／停用 |
| `/aqot on` | 啟用 |
| `/aqot off` | 停用 |
| `/aqot debug` | 開關除錯訊息（在聊天視窗顯示插件的每次動作） |

設定會跨角色保存。

## 已知行為

- 在任務日誌中點選一個已追蹤的任務，也會把它置頂。對遊戲來說，這和點追蹤列表上的標題是同一個動作，插件無法區分。
- 在 0.5 秒內連續點兩個不同任務的圖示，專注可能會回到第一個任務。
- 置頂的任務不會存檔。登入或重載介面後，會先以當下的專注任務作為置頂任務。

## 運作原理

在永恆中，新加入追蹤的任務會排在追蹤清單最前面。插件利用這一點，把要置頂的任務「取消追蹤再加回追蹤」，其他任務的順序不受影響。

取消追蹤會讓遊戲同時取消該任務的專注，所以插件會在加回追蹤後把專注設回去。

插件只使用非保護的 API，戰鬥中也能運作，不會造成介面污染（taint）。

## 相容性

- 支援版本：魔獸世界：永恆 1.60.1（Interface `16001`）
- 不支援正式服與其他經典版本。
